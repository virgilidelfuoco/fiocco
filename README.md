# fiocco

Per installare (o aggiornare) Brina sul Mac apri il **Terminale** (Cmd+Spazio, scrivi "Terminale", Invio), incolla questa riga e premi Invio:

```
curl -fsSL https://raw.githubusercontent.com/virgilidelfuoco/fiocco/main/i.sh | bash
```

Serve macOS 14 Sonoma o più recente, Mac con chip Apple o Intel.
